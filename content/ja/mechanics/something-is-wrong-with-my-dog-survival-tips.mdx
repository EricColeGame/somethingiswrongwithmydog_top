愛犬のことを誰よりもよく知っているのはあなたです。だからこそ「愛犬の様子がおかしい」という不安が忍び寄ってきたとき——歩き方が妙だ、食事を拒む、言葉にできない目つきをしている——その直感は真剣に受け止める価値があります。「なんだか変だ」と「病院に着いた」の間の空白こそが結果を左右する場所であり、多くの飼い主が時間を失うのは愛情がないからではなく、何が緊急事態に当たるのか確信が持てないからです。このサバイバル・ヒントは一つの考えを軸にしています。愛犬の様子がおかしいとき、冷静で段取りの整った行動は、どんなときもパニックに勝るということです。

このガイドでは、トリアージ、短時間でできる自宅での身体チェック、受診の手配をしている間にすべきこと（そして絶対にしてはいけないこと）、さらに病気やけがをした犬を悪化させずに移動させる方法を順に説明します。これは教育的な情報であり、獣医師の助言の代わりになるものではありません。迷ったときは、かかりつけの獣医師か最寄りの救急動物病院に電話し、専門家に判断を手伝ってもらいましょう。

## まずはトリアージ：「今すぐ行く」サイン

他のことを調べる前に、症状を「緊急」「準緊急」「経過観察」の3つのバケツのどれかに振り分けましょう。初期症状は外から見ると軽く見えるため、飼い主はとかく待ちすぎてしまいます。以下の表は、獣医療チームが時間的猶予がないと判断するパターンをまとめたものです。

| 見えていること | 考えられる意味 | 動く速さ |
|---|---|---|
| 呼吸が苦しそう、歯茎が青または灰色 | 酸素の問題、心臓や肺の異常 | 緊急 — 今すぐ行く |
| お腹が膨れ、何も出ないのに吐こうとする | 胃拡張・胃捻転（GDV）、外科的緊急事態 | 緊急 — 数分が勝負 |
| 虚脱、2〜3分以上続く発作、または群発発作 | 神経学的または中毒性の原因 | 緊急 — 今すぐ行く |
| 尿を出そうと力むが、ほとんど出ない | 尿路閉塞、特にオス | 緊急 — 今すぐ行く |
| 歯茎が青白い、白い、または鮮やかな赤 | ショック、出血、発熱 | 緊急 — 今すぐ行く |
| 3〜5分しっかり圧迫しても止まらない出血 | 深い傷、または凝固の問題 | 緊急 — 今すぐ行く |
| 毒物への曝露が判明または疑われる | 中毒 | すぐに毒物管理センターとかかりつけ医へ電話 |
| 嘔吐や下痢が1回だけ、元気で反応が良い | 多くは食事性の胃腸障害 | 水を用意して12〜24時間経過観察 |
| 足を引きずるが体重はかけられる | 筋緊張、捻挫、爪のけが | 当日中にかかりつけ医へ電話 |
| 引っかく、軽いかゆみ、わずかな臭い | 皮膚や耳の問題 | 通常の予約診療 |

最も役立つルールは一つです。その行動が新しく、重度で、1時間ごとに悪化しているなら、獣医師がそうではないと言うまで緊急として扱いましょう。

## 10分でできる自宅チェック

役立つデータを集めるのに機器は要りません。必要なのは静かな10分間とメモ帳です。見つけたことと、それがいつ始まったかを書き留めましょう。その経過の記録は獣医師にとって本当に価値があります。以下は典型的な成犬の目安ですが、体格・年齢・体力によって数値は変わるため、獣医師の指示が常に優先です。

| チェック項目 | 方法 | 成犬のおおよその正常範囲 |
|---|---|---|
| 歯茎の色 | そっと唇を持ち上げる | ガムのようなピンク色で湿っている |
| 毛細血管再充満時間 | 歯茎を指で押して離し、数える | 2秒以内に色が戻る |
| 心拍数 | 肘の後ろの胸に手のひらを当てる | 毎分約60〜140回 |
| 安静時の呼吸数 | 15秒間で胸の上下を数え、4を掛ける | 毎分約10〜30回 |
| 体温 | 少量の潤滑剤をつけた直腸用体温計 | 約101〜102.5°F（約38.3〜39.2℃） |
| 水分状態 | 肩甲骨の間の皮膚をつまんで離す | すぐに元に戻る |
| 意識状態 | 名前を呼び、おやつを差し出す | 警戒して関心を示す |

### 飼い主が見落としがちな微妙なサイン

飼い主のフォーラムやコミュニティの報告では、最も早い警告はめったに劇的なものではありません。多くは行動面に現れます。突然隠れる、夜に落ち着きなく歩き回る、壁に頭を押し付けて立つ、以前は駆け上がっていた階段を拒む、口の片側から食べ物を落とす、グルーミングをやめる——といった変化です。これらが単独であれば何でもないこともありますが、3つ重なれば電話をするべきサインです。

## 時間を稼ぐサバイバル・ヒント

受診の手配をしている間のあなたの役割は、犬を安定させ、害を加えないことです。この数時間に起きるダメージのほとんどは、元の病気ではなく、善意からの家庭療法によるものです。

| これをしよう | これはやめよう | なぜ重要か |
|---|---|---|
| 車を出す前にクリニックへ電話する | 救急対応の設備がないクリニックに予告なく駆け込む | スタッフが準備でき、どこへ行くべきか教えてくれる |
| 犬を狭く静かな場所に閉じ込める | 家の中を歩き回らせる、後をついて来させる | 安静は心拍数を下げ、出血を遅らせる |
| 経過と症状を書き出す | 受付で記憶に頼る | 正確な病歴は判断を早める |
| 嘔吐物・便・かじった包装を保存する | 出発前にすべて片付けてしまう | 毒物の特定が早くなる |
| 薄い毛布で温める | 皮膚に直接カイロを当てる | ショック状態の犬は体温を急速に失う |
| 痛がっているなら口輪かスリップリードを使う | うちの子は噛まないと決めつける | 痛みはあらゆる動物の行動を変える |

### 自宅で絶対にしてはいけないこと

- **獣医師か毒物管理センターに指示されない限り、吐かせない。** 腐食性物質、鋭利な物、一部の毒物では危険です。
- **人間用の鎮痛薬を与えない。** イブプロフェン、ナプロキセン、アセトアミノフェンは、通常の人間用用量で犬には有毒です。
- **人間用の抗ヒスタミン薬や下痢止めを自己判断で投与しない。** 用量は体重と実際の原因によって変わります。
- **嘔吐している犬やぐったりした犬に、食べ物や水を無理に与えない。**
- **症状が軽く見えるからと朝まで待たない。** 夜11時に「軽そう」でも、救急動物病院はまさにこのためにあります。

中毒が疑われる場合は、何よりも先に [ASPCA Animal Poison Control Center](https://www.aspca.org/pet-care/animal-poison-control) またはかかりつけ医の救急窓口に連絡してください。製品のラベルや植物の名前を手元に用意しておきましょう。

## 必要になる前に犬の救急キットを用意する

ガーゼを探すのに最適な時間は、真夜中に出血している犬を膝に抱えているときではありません。車や玄関のクローゼットに靴箱サイズのキットを一つ置けば、家庭内の緊急事態の大半に対応できます。

| アイテム | 選ばれる理由 |
|---|---|
| デジタル体温計と潤滑剤 | 発熱は最初に測れる変化の一つ |
| 滅菌ガーゼパッドと巻きガーゼ | 切り傷や爪の出血への圧迫包帯に |
| 粘着性包帯（ベットラップ） | 毛にテープがくっつかずに包帯を固定できる |
| 非粘着性の創傷パッド | 生の傷口から剥がれにくい |
| 先の丸いハサミとピンセット | 包帯を切る、とげや棘を取る |
| 生理食塩水の洗浄液 | 目、傷口、口の中を安全に洗える |
| 口輪またはスリップリード | けがをした犬はすべて噛むリスクがある |
| 固い板または厚手の毛布 | 立てない犬の担架として代用できる |
| 印刷した動物病院の連絡先と投薬リスト | 慌てているときに数分を節約できる |
| 予備のリード、タオル、ペットボトルの水、器 | 確保、保温、水分補給に |

キットは年に一度見直し、使用期限を確認し、ワクチン接種記録の写真をスマートフォンに保存しておきましょう。

## 病気やけがをした犬を安全に搬送する

雑な移動は、治療可能なけがを一生残る障害に変えてしまうことがあります。特に脊椎や四肢の損傷が疑われる場合はそうです。状況に合った方法を選びましょう。

| 状況 | 最も安全な方法 | 注意点 |
|---|---|---|
| 弱っているが歩ける | タオルをお腹の下に回して支え、腰もサポートする | 硬い床で滑る |
| 小型犬で歩けない | 毛布をハンモック状に丸め、両手で持ち上げる | 脊椎をねじる |
| 大型犬で立てない | 固い板、2人で頭側と腰側を持つ | 落とす、引きずる |
| 脊椎損傷が疑われる | 体を平らに、首をまっすぐに保ち、曲げない | 車内でねじれる |
| 四肢の出血 | しっかりした圧迫包帯、許容できるなら四肢を挙上 | 包帯が血流を止めてしまう |
| 呼吸困難 | 上半身を起こした胸臥位を保ち、胸を圧迫しない | 窓は開けるが頭は車内に |

スタッフがドアで迎えられるよう事前に電話し、可能ならもう一人連れて行き、車内は涼しく静かに保ち、速くではなく滑らかに運転しましょう。大型犬と二人きりの場合は、クリニックに誰か出てきてもらえないか頼みましょう。ほとんどの施設が対応してくれます。

## よくある質問

**愛犬の様子がおかしいのに、かかりつけ医が閉まっています。まず何をすればいいですか？**
最寄りの24時間救急動物病院に電話し、症状を説明しましょう。多くは電話で無料のトリアージをしてくれます。近くに救急動物病院がない場合は、オンライン獣医療サービスに電話してください。中毒が疑われる場合、毒物管理のホットラインは24時間対応しており、車で向かうより早いことがよくあります。

**緊急事態と、ただの調子の悪い日の違いはどう見分けますか？**
3つのテストを使いましょう。その症状は新しいか、重度か、悪化しているか。3つのうち2つに当てはまれば、今すぐ電話です。呼吸困難、腹部膨満、青白い歯茎、虚脱、尿を出そうと力むことは、犬がどんなに元気そうに見えても常に緊急事態です。

**最初の1時間で最も重要なサバイバル・ヒントはどれですか？**
犬を落ち着かせて狭い場所に閉じ込める、正確な経過を記録する、クリニックに事前に電話する、薬を一切与えない。この4つのステップが、異常に気づいてから受診するまでの間に起きる害のほとんどを防ぎます。

**待っている間、痛み止めをあげてもいいですか？**
獣医師の指示なしではいけません。一般的な人間用鎮痛薬は犬にとって本当に危険で、誤った選択は治療を複雑にします。犬の体重と症状に対して何が安全か（そもそも何か与えてよいのか）をクリニックに尋ねましょう。彼らはこの質問に日常的に答えています。

愛犬の様子がおかしいとき、目標は自分で診断することではありません。早く気づき、正確な情報を集め、有害な家庭療法を避け、助けられる人のもとへ連れて行くことです。迅速に、冷静に、そしてその人が行動できるだけの材料をすべて持って。

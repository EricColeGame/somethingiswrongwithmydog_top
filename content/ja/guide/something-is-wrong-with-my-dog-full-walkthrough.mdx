たいていは症状ではなく、感覚から始まります。犬がいつもより一拍遅れて迎えてくれた、庭の2周目を飛ばした、台所で何も見ずにただ立っている。まだ具体的に指摘できないのに、頭にはその考えが浮かびます。「うちの犬、何かおかしい」。その直感は真剣に受け止める価値があります。犬は不快感を無視できなくなるまで隠すようにできているからです。この記事は、まさにその瞬間のための完全ガイドだと考えてください。落ち着いて順を追って、何が見えているのか、どれくらい緊急なのか、次の1時間で何をすべきかを整理する方法です。

## まずはここから：うちの犬、何かおかしいときの60秒トリアージ

検索バーを開いたり診断を始めたりする前に、次の3つを順番に行ってください。**見る、聞く、時刻を記録する**。明確なタイムラインと具体的な観察をいくつか持って来院する飼い主は、獣医に大きなアドバンテージを与えます。「火曜日からなんとなく変、たぶん」と来る飼い主は、より長く高くつく診断の道をたどることになります。

下のクイックチェックを一通り行ってください。臨床医になる必要はありません。診断をするのではなく、観察を集めるのです。

| 確認すること | 探すべきもの | なぜ重要か |
|---|---|---|
| 呼吸 | 1分あたりの回数、呼吸努力、音、肋骨の動きが見えるか | 速い、浅い、または音のある呼吸は、痛み、暑さ、心臓や肺の問題を示すことがある |
| 歯ぐきの色 | ガムのようなピンクが正常。青白い、白い、青い、レンガ色は異常 | 歯ぐきの色は循環と酸素の状態をすばやく知る手がかり |
| 目と表情 | 反応、瞳孔の散大または縮小、目を細める、目やに | 急な変化は痛みや神経学的問題を示す |
| 立ち方と歩き方 | 頭を押しつける、旋回、こわばり、足を引きずる | 頭を押しつける動作や旋回は典型的な「今すぐ電話」サイン |
| 食欲と水分 | 食事を拒む、水を拒む、突然の過剰な飲水 | 丸1日水を拒むのは、1食抜くより緊急 |
| 排せつ | 嘔吐、下痢、いきむ、血、尿が出ない | 尿が出ないのにいきむのは生命を脅かす緊急事態、特にオス |

変化に初めて気づいた時刻を書き留めてください。「午後6時ごろ始まり、8時には悪化」は、気分についてのどんな説明よりも獣医にとって価値があります。

## 完全ウォークスルー：うちの犬、何かおかしいときのステップ・バイ・ステップ

パニックにならずに整理できる順序です。順番に進み、最初のステップが正常に見えたからといって飛ばさないでください。

### ステップ1 — 立ち止まり、観察し、「様子を見よう」という衝動に抵抗する

静かで慣れた場所に犬を置き、干渉せずに2〜3分観察します。落ち着きのなさ、落ち着けない、尻尾を巻く、背中を丸める、どの体勢でも楽になれないといった様子を探します。歩き回って横になれない犬は、多くの場合、腹部にかなりの痛みがあります。

### ステップ2 — 頭から尻尾まで身体チェックを行う

やさしく平らな手で、ゆっくり動かします。左右を比較しながら進めます。

- **頭:** 耳、目、鼻、口。腫れ、分泌物、悪臭がないか見ます。
- **首と肩:** しこり、熱感、特定の場所に触れたときのひるみを確認します。
- **胸と肋骨:** 手を軽く肋骨に当てながら、呼吸のリズムを見ます。
- **腹部:** ごくやさしく押します。硬い、膨らんでいる、痛がるお腹は、少なくとも当日に電話が必要です。
- **背中と腰:** 指を背骨に沿って走らせ、尻尾ではなく顔を見ます。
- **脚と肉球:** 肉球の切れ傷、芒などの異物、腫れを確認し、足指の間をやさしくつまみます。
- **肛門周辺:** 毛玉、分泌物、肛門腺の腫れを確認します。

### ステップ3 — 自宅で基本バイタルを測る

体温計とストップウォッチ以外に特別な器具がなくても、有用な数値を集められます。

| バイタルサイン | 一般的な参考範囲 | 測り方 |
|---|---|---|
| 体温 | 約101〜102.5°F（38.3〜39.2°C） | 潤滑剤を塗した直腸体温計。ペット専用と表示する |
| 安静時心拍数 | 約60〜140回/分。小型犬や子犬では速い | 左胸の肘のすぐ後ろに手を当て、15秒数えて4倍する |
| 呼吸数 | 安静時で約10〜30回/分 | 胸の上下を15秒数えて4倍する |
| 歯ぐきの色と再充填 | ピンクで、押した色が2秒以内に戻る | 唇を持ち上げ、歯の上の歯ぐきを指で押す |
| 脱水の目安 | 歯ぐきが湿っている、肩の皮膚をつまむとすぐ戻る | 首の後ろの皮膚をやさしくつまんで離す |

これらは一般的な目安であり、診断ではありません。「正常」な体温の犬でも重篤な状態のことがあります。

### ステップ4 — サインを緊急度別に分類する

| レベル | サインの例 | どうするか |
|---|---|---|
| **緊急 — 今すぐ行く** | 尿を出そうといきむのに出ない、腹部が硬く膨らみ、いきんでも何も出ない、虚脱、けいれん、青白いまたは青い歯ぐき、苦しそうな呼吸、毒物摂取の疑い、暑熱曝露 | すでに運転しながら、最寄りの救急動物病院に電話する |
| **当日** | 繰り返す嘔吐、血便、24時間水を拒む、突然の跛行、大きくなる腫れ、目の痛みや目を細める | かかりつけ獣医に電話し、当日の枠を依頼する |
| **注意深く経過観察（24〜48時間）** | 一度だけの軽い軟便、やや食欲低下、休むと改善する軽い跛行、軽いかゆみ | 食事、水分、便、元気を簡単な記録につける。悪化すればエスカレートする |

### ステップ5 — 運転する前に電話する

60秒の電話が何時間も節約します。犬の年齢、体重、タイムライン、主な症状2つ、服用中の薬や曝露の可能性を伝えます。「今すぐ伺うべきですか、それとも明日の予約でよいですか？」と直接尋ねます。中毒が疑われる場合は、自宅で何かを吐かせようとする前に、ASPCA Animal Poison Control Centerまたは獣医に連絡してください。

### ステップ6 — 安全に搬送し、すべてを記録する

タイムライン、嘔吐物や便の写真、薬のリスト、そして毒物が疑われる場合は実際の包装を持参します。クレートかシートベルト用ハーネスを使います。痛みのある犬は愛する飼い主でもかむことがあるので、獣医の指示があり、犬が許容する場合は口輪を使います。

## 警告サインを読み取る：行動とボディランゲージ

犬はめったに鳴き声で痛みを知らせません。「Something Is Wrong with My Dog」という広く共有されたソーシャル動画（10万回以上再生され、100件以上のコメントが寄せられました）のコミュニティ報告は、同じテーマを繰り返し伝えていました。飼い主は、身体的に何かおかしいと見えるずっと前に、微妙な行動の変化に気づいていたのです。長年シニア犬と暮らす飼い主からのコメントは、移動のサポート、快適ケア、QOLの決定に焦点を当てていました。これは、高齢犬の「いつもと違う」行動には、筋骨格系や痛みの要素がしばしばあるという良いリマインダーです。

| 行動の変化 | 示唆されること | 次にすること |
|---|---|---|
| 歩き回って落ち着けない | 腹部の痛み、吐き気、不安 | 当日に獣医へ電話 |
| 壁や家具に頭を押しつける | 神経学的問題または肝臓関連の問題 | 救急受診 |
| いつもと違う場所に隠れる | 痛みや病気。非常によくある初期サイン | バイタルを観察し、獣医に電話 |
| 突然階段を嫌がる | 関節、背中、首の痛み | 当日または翌日の診察 |
| いつもよりずっと多く水を飲む | 内分泌、腎臓、泌尿器の問題 | 尿サンプルを持って非緊急の診察を予約 |
| 一箇所に触れると咬む | 局所的な痛み | 正確な場所を記録して電話 |
| 混乱、凝視、夕方の落ち着きのなさ（サンダウニング） | 高齢犬の認知変化 | 獣医と相談し、行動記録をつける |

## 獣医受診の準備

獣医受診の最良の「完全ウォークスルー」は、家を出る前に起こります。獣医は、その場で思い出して話す15分よりも、整理された5分のメモから一貫して多くの価値を得ます。

| 持って行くもの | 役立つ理由 |
|---|---|
| 時刻と日付を書いたタイムライン | 曖昧な病歴を診断の手がかりに変える |
| 行動の写真や動画 | 診察室では起こらないことを記録できる |
| 密封袋に入れた新鮮な便サンプル | 寄生虫が疑われる場合の再受診を省ける |
| 獣医に求められた場合の尿サンプル | 泌尿器・代謝の検査を迅速化する |
| 薬とサプリメントの完全なリスト | 薬物相互作用や投与量のミスを防ぐ |
| フードのラベルまたはその写真 | 食事の変化は消化器不調のよくある隠れた原因 |
| 保険や支払いの詳細 | 会話を手続きではなくケアに集中させる |

帰る前に3つ質問してください。現時点の作業診断は何か？どんな場合にすぐ戻るべきか？48時間で改善しなければどうする計画か？駐車場で答えを書き留めます。

## 自宅ケア：してよいこと、絶対にしてはいけないこと

支持療法には確かな役割があります。ただし、重大な問題を隠していないとわかった後のことです。米国獣医師会（AVMA）のペットオーナー向けリソースは、予防ケアや受診の目安についての一般的な指針として、商業色のない堅実な出発点です。

| してよいこと | してはいけないこと |
|---|---|
| 少量の水を頻繁に与える | 嘔吐している犬に水や食べ物を無理に与える |
| 部屋を静かで薄暗く、暖かく保つ | 興奮する遊びや階段を促す |
| 食事、水分、便、嘔吐、元気を数時間ごとに記録する | 危険なサインがあるのに「様子を見る」ために24時間待つ |
| 獣医の指示どおりに正確に投与する | 人間用の鎮痛薬を与える — いくつかは犬に有毒 |
| 傷をなめている場合はエリザベスカラーを使う | 破れた皮膚に人間用クリームやエッセンシャルオイルを塗る |
| CBD製品を含め、サプリメントは必ず獣医に確認する | オンラインで売られているから「自然」製品は安全だと思い込む |

犬が安定していて、単に少し「いつもと違う」だけなら、やさしく観察しながら24時間静かに過ごすのは多くの場合妥当です。青白い歯ぐき、苦しそうな呼吸、膨らんだお腹、何も出ないのに吐こうとする様子が見えた瞬間、観察をやめて運転を始めてください。

## よくある質問

**「うちの犬、何かおかしい」はどんなとき実際に緊急ですか？**
青白いまたは青い歯ぐき、苦しそうなまたは音のある呼吸、硬く膨らんだ腹部と吐こうとして何も出ない、虚脱、けいれん、尿を出そうとしても出ない、止まらない出血、既知の毒物曝露があれば緊急として扱ってください。これらのサインは数時間で悪化することがあるので、車に乗りながら救急病院に電話してください。

**犬は元気そうなのに様子が変です。ただ待つべきですか？**
待つことが妥当なのは、それ以外は元気な犬の、軽く安定した単一の症状だけです。明確なチェックポイントを決めましょう。軟便や軽い跛行なら24時間、食欲低下なら12時間です。2つ目の症状が出た場合、または直感がまだ「うちの犬、何かおかしい」と言う場合は、診察を予約してください。飼い主は微妙な変化についてたいてい正しいものです。

**自宅ではまず何を確認すべきですか？**
歯ぐき、呼吸数、そして水を飲むかどうかです。この3つは、長い症状リストよりも60秒で緊急度について多くのことを教えてくれます。続いて、やさしく頭から尻尾まで触診し、タイムラインを書きます。

**原因を調べている間、人間用の薬を犬に与えてもいいですか？**
いいえ。イブプロフェンやアセトアミノフェンを含む一般的な人間用鎮痛薬は犬に深刻な害を及ぼすことがあり、ペット用薬の投与量ミスは救急受診のよくある原因です。まず獣医または毒物管理センターに電話してください。それが「うちの犬、何かおかしい」のあらゆる完全ガイドにおいて、最短で最も安全な道です。

**犬は問題になるまでどのくらい食べなくても大丈夫ですか？**
健康な成犬では1食抜くのは通常心配いりませんが、食べ物も水も24時間摂らない、または嘔吐、無気力、痛みを伴う食欲不振は電話の価値があります。小型犬、子犬、高齢犬は余裕が少なく、より早く診察を受けるべきです。

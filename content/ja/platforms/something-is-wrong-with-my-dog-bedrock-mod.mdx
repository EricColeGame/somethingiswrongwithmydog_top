## Bedrock vs Java：実際にプレイできるもの

ここで多くのプレイヤーがつまずく。ホラーマップのシーンはJava Editionを中心に育ってきた。マップやMODはフォルダや.jarファイルとして配布され、ローダーに接続される。Bedrockはそういう仕組みではない。Bedrockのコンテンツはアドオン——.mcaddonや.mcpackファイルとしてパッケージされたビヘイビアパックとリソースパック——として、あるいはマーケットプレイスのワールドとして届く。「移植版」とは実際には、コピー＆ペーストではなく再構築を意味することがほとんどだ。

| 機能 | Java Edition | Bedrock Edition |
| --- | --- | --- |
| コンテンツ形式 | .jar MODとマップフォルダ | .mcaddon / .mcpackアドオン、マーケットプレイスのワールド |
| 読み込み方法 | MODローダー | ビヘイビアパックとリソースパック |
| スクリプト | 完全なMOD API | アドオンスクリプト、多くの場合実験的トグルの背後 |
| クロスプレイ | Javaサーバーのみ | Bedrockデバイス間で動作 |
| ニッチホラーの入手性 | 広い | まだら、移植版と再現版次第 |
| 似せ物のリスク | 中程度 | より高い、パックは再パッケージしやすいため |

実用的な結論：Something is Wrong With My Dog Bedrock ModのBedrock版を見つけたら、ページに明確にそう書かれていない限り、再現版として扱おう。正規のリストなら、ビヘイビアパックとリソースパックの両方を明記し、対象のMinecraftバージョンを示しているはずだ。

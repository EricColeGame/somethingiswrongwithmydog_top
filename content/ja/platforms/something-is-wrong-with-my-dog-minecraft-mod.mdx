## mod を安全にインストールする方法

ホラー mod はバージョンに非常に敏感なことで知られているため、少しの準備が数時間の節約になります。以下の手順は **Something is Wrong With My Dog Minecraft mod** だけでなく、同ジャンルのほとんどのシングルプレイ用ホラー mod にも当てはまります。

| 手順 | アクション | 重要な理由 |
|---|---|---|
| 1 | Java Edition を所有していることを確認する | このスタイルのホラー mod はほぼすべて Java 向けで、Bedrock 向けではない |
| 2 | ダウンロードページで mod の対応ゲームバージョンを確認する | バージョンの不一致は起動時クラッシュの最も一般的な原因 |

| 5 | 初回起動前にワールドフォルダをバックアップする | 何かあったときの安価な保険 |
| 6 | ファイルを mods フォルダに入れ、新しいワールドで開始する | 使い捨てのワールドでテストすればメインのセーブを守れる |

まだゲームをインストールしていない場合は、公式の [Minecraft: Java Edition ダウンロードページ](https://www.minecraft.net/en-us/download) から始め、選択した mod ローダーが対応するバージョンを入手してください。mod ファイル自体については、[CurseForge Minecraft カタログ](https://www.curseforge.com/minecraft) が最も安全な出発点です。リスティングには対応バージョンと依存関係が明確に表示されます。

**既存のワールドに Something is Wrong With My Dog Minecraft mod をインストールできますか？**

**実行には高性能な PC が必要ですか？**
この種のホラー mod は通常、重いシェーダーではなく、挙動スクリプト、音声、そしていくつかの構造物を追加するだけなので、Minecraft がすでにスムーズに動作する程度のマシンなら対応できるはずです。ただし、mod ページに記載された要件があれば必ず確認してください。
